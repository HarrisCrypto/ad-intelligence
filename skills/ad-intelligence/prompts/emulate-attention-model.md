# Emulate a study + attention model

**Steal structure. Never steal brand facts, reviews, or claimed performance.**

Studies (`studies/corpus.json`, also in retrieve `studies`) distill viral TikTok, high-performing paid, and top-tier brand-film **jobs**. Attention models add second-by-second timing. Together they tell you *what to emulate* and *when*; `references/human-build-os.md` tells you *how a human builds it*.

## Inputs

- Study id from retrieve `studies.primary` (or `studies/corpus.json`)
- Attention model id from `references/attention-models.json` (also returned by `retrieve.mjs`)
- Optional: 1–3 live ads you observed in public libraries (`references/ad-libraries.md`)
- Pattern ids from retrieve picks
- User brief / URL gather (`brief-from-url.md`)

## Emulation checklist

Copy into the package **Concept** or **Self-critique** notes:

1. **Study id** + **model id** + why they fit this niche/platform (`when_to_emulate`; skip if `when_not`)  
2. **0–3s** — same *job* as the study/model (confession / macro / pain object / spectacle / text-first), new words  
3. **Beat timing** — keep row count and ≈seconds from study.structure / model.timing; rewrite every VO/on-screen cell in quotes  
4. **Shot grammar** — camera/light/product lock rules from the model + study.steal  
5. **Animation / cut** — cut rate, text slam length, when logo may appear  
6. **Words** — obey model `words_do` / `words_dont` / `anti_slop` and study.never_copy  
7. **Human build** — map study.human_build steps to your rung (connected / handoff / assembler / package-only)  
8. **Craft** — real HEX + real fonts + motion + E1 (lint)  
9. **Dual-track** — for serious brands, cinema/hero twin ≠ primary UGC (same JTBD)

## Refusal

Do not deliver if you only changed product name inside a competitor’s lines, ignored `never_copy`, or collapsed timing to “hook / middle / CTA” without ≥6 rows.
