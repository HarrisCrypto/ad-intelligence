# Emulate an attention model

**Steal structure. Never steal brand facts, reviews, or claimed performance.**

## Inputs

- Attention model id from `references/attention-models.json` (also returned by `retrieve.mjs`)
- Optional: 1–3 live ads you observed in public libraries (`references/ad-libraries.md`)
- Pattern ids from retrieve picks
- User brief / URL gather (`brief-from-url.md`)

## Emulation checklist

Copy into the package **Concept** or **Self-critique** notes:

1. **Model id** + why it fits this niche/platform  
2. **0–3s** — same *job* as the model (confession / macro / pain object / spectacle / text-first), new words  
3. **Beat timing** — keep row count and ≈seconds; rewrite every VO/on-screen cell in quotes  
4. **Shot grammar** — camera/light/product lock rules from the model  
5. **Animation / cut** — cut rate, text slam length, when logo may appear  
6. **Words** — obey `words_do` / `words_dont` / `anti_slop`  
7. **Craft** — real HEX + real fonts + motion + E1 (lint)  
8. **Dual-track** — for serious brands, cinema/hero twin ≠ primary UGC (same JTBD)

## Refusal

Do not deliver if you only changed product name inside a competitor’s lines, or if timing collapsed to “hook / middle / CTA” without ≥6 rows.
