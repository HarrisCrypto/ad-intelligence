# Cross-tool prompt recipes (film-quality ads)

Use with the pattern’s timed script. Swap bracket tokens only.

## Seedance — see `seedance-prompt-contract.md`

Primary for **Higgsfield-peer / ByteDance-quality** spots.

## Kling / Runway / Luma — image-to-video product move

```text
Image-to-video from product still. Camera: slow push-in, 35mm, shallow DOF.
Motion: [hand enters / pour / turntable 30° / fabric ripple].
Keep label sharp; no morphing; cinematic grade [describe]; 5–8s; 9:16.
Negative: warp text, extra limbs, logo melt, watermark.
```

## Sora / Veo — brand world (hero film)

```text
Photoreal commercial. [World]. Lighting: [motivated]. Lens: anamorphic 40mm.
Shot list inside one prompt with timecodes 0–3 / 3–12 / 12–20 / 20–30.
Product identity from reference. No on-screen paragraphs. End on hero pack.
```

## Midjourney / FLUX — keyframe / static ad frame

```text
Hero product photograph, [surface], [lighting], commercial advertising still,
centered, packshot accuracy, 85mm, f/4, --ar 4:5 --stylize low
```

## Ideogram / GPT-Image — text-on-frame endcard

```text
Clean endcard, solid [brand color], product small bottom, large CTA text “[CTA]”,
minimal, high legibility, no busy background, 4:5
```

## ElevenLabs VO

```text
Tone: [confident/warm]. Pace: 145 wpm. Script: “[exactly the VO lines]”.
No smile-voice. Slight pause after hook sentence.
```

## Suno bed (paid-safe original)

```text
Instrumental only, [energy], modern commercial bed, no vocals, 15–30s loopable,
genre [electronic/cinematic/lofi], brand-safe.
```

## CapCut finishing checklist (always)

1. Import master  
2. Auto captions → style large, high contrast  
3. Hook text overlay 0–3s  
4. Endcard last 3s  
5. Loudness normalize  
6. Export 9:16 1080p + required aspects  

## Meta primary text recipe

```text
Hook line (matches video 0–3s).
One mechanism sentence.
One proof placeholder or omit.
One CTA.
```
