# Angle axes — multiply concepts without slop

Use when Concept needs 3 options (or A/B/C variants).  
**Original checklist for this skill** — steal structure, write new words. Never invent proof.

Pick **one primary axis** + optionally one secondary. Each option must change the *idea*, not just adjectives.

| Axis | Question | Fits |
| --- | --- | --- |
| **Confession** | What costly mistake does the viewer admit? | UGC, SaaS, beauty |
| **Demonstration** | What do we *show* in motion that text can’t? | Product, food, UI |
| **Enemy process** | What old way looks ridiculous on camera? | PAS, fintech, ops |
| **Identity POV** | Who does the viewer become mid-ritual? | GRWM, fashion, fitness |
| **Geo / specific** | What place/specialty makes this local-true? | Local services |
| **Open loop** | What question must Part 1 leave unpaid? | Series, listicle |
| **Social mirror** | Whose real words (ledger-backed) carry it? | Proof, BOF |
| **Spectacle physics** | What product physics is the scroll-stop? | Hero, macro, CGI |

## Rules

1. Option (1) = the AI-default you **refuse** (name it).  
2. Options (2)(3) = stronger; pick one → “Not the default because…”  
3. Bind the chosen angle to an **attention model id** (`am_*`).  
4. If you only swapped the product name inside the same scene, rewrite.
