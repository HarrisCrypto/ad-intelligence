# Elite creative OS — agency-grade ads (with or without Higgsfield)

Read this before filling the package. Compliance (sheets, ledger, lint) prevents slop **lies**. This file prevents slop **looks**.

**Bar:** the package should read like a custom motion template from a top performance creative shop — not a generic LLM ad outline. Every beat names lens, light, type, motion, and finish. Vague “cinematic product shot” = fail.

Works on **connected**, **handoff**, and **assembler** rungs. Tools change; craft does not.

---

## 1) Mindset (non-negotiable)

1. **One job.** One JTBD. One primary CTA. Everything else is noise.  
2. **Design the cut, then generate.** Storyboard → craft system → prompts — never prompt-first vibes.  
3. **Post owns type + logo + legal.** Models do motion/atmosphere. CapCut/Figma/After Effects own endcards.  
4. **Identity > spectacle.** Wrong pack/label fails even if “pretty.”  
5. **Muted-first.** If the hook needs sound to work, rewrite the visual.  
6. **Honest proof.** Prestige craft does not invent metrics.  
7. **Name real tools.** Never invent Seedance/Higgsfield jobs. Use `alternative-model-routing.md` when those are absent.

---

## 2) Custom-template standard (what “top shop” packages include)

Treat every delivery as a **finisher-ready custom template**:

| Layer | Must specify |
| --- | --- |
| **Narrative** | Hook machine, beat map, JTBD, one CTA |
| **Visual system** | Palette HEX (approx OK if ASSUMED), contrast, grade, grain/halation |
| **Typography** | Font roles (display / body / CTA), sizes, weight, safe zones, max words on screen |
| **Motion grammar** | Camera verbs per beat, speed ramps, cut rhythm (frames or seconds) |
| **Sound** | Bed / VO / SFX roles; paid-safe path; when muted captions carry |
| **Endcard** | Logo treatment, CTA plate, legal line, hold length, safe margins |
| **Aspects** | Separate 9:16 / 1:1 / 16:9 designs — not center-crop |
| **Assembler units** | K# stills + C# clips + E# endcard with tool names |

If a section is empty prose (“nice lighting”), rewrite until a motion designer could build it without asking you.

## 3) Hook machines (0–3s)

Pick **one** primary machine; name it in Hooks:

| Machine | Visual | Captions |
| --- | --- | --- |
| **Pattern interrupt** | Unexpected action / mismatch in frame 0 | ≤6 words |
| **POV identity** | Viewer-as-camera; immediate situation | “POV: …” ≤8 words |
| **Macro lust** | Extreme close detail; texture readable | Noun + sensory verb |
| **Problem flash** | Concrete pain object (bill, drip, empty chair) | Pain noun only |
| **UI aha** | Real screen; one highlight | Verb the outcome |
| **Social proof flash** | Real review card / NAP (user-supplied only) | Quote fragment |

**Banned in 0–3s:** logo open, brand manifesto, multi-CTA, “we’re excited to announce.”

---

## 4) Edit rhythm (performance craft)

Default 15–30s spot:

| Window | Job | Craft |
| --- | --- | --- |
| 0–2s | Thumbstop | Hard visual change; caption on |
| 2–5s | Orient | Who/where/what in one clear frame |
| 5–12s | Desire / mechanism | Product or UI lock; one idea |
| 12–20s | Proof or deepen | PLACEHOLDER-safe; or demo |
| Last 3–5s | CTA endcard | Static plate; logo SVG; one CTA; hold |

Cut on **action** or **caption change**, not every half-second. Aim for readable holds: hero product ≥1.2s continuous; CTA ≥2.5s.

---

## 5) Visual system (force specificity)

### Palette
- 1 dominant, 1 support, 1 accent (HEX or named brand tokens)  
- Background: never flat default gray — atmosphere (gradient, practical light, location texture)  
- Avoid generic AI-default purple glow / cream-serif terracotta clichés unless brand-true  

### Grade
Name a grade: `clean daylight` · `cool clinical` · `warm tungsten practicals` · `high-contrast editorial` · `flat UI documentary`  
State: contrast, saturation, skin/product priority (product label always readable).

### Lens & camera language (per beat)
Use concrete verbs: push-in · orbit · macro static · whip-pan · locked-off · handheld micro-sway · top-down tabletop  
State FOV feel: `35mm walk` · `50mm portrait` · `100mm macro` · `UI screen record 100%`

### Negative space
Lower **20%** caption-safe; right/left edge safe for platform UI; no critical label in burned TikTok UI zones.

## 6) Typography system (custom template)

| Role | Spec |
| --- | --- |
| **Hook display** | Bold condensed or brand display; 2 lines max; high contrast plate or clean knockout |
| **Body / VO captions** | Neutral sans; ≤2 lines; appear on phrase boundaries |
| **CTA** | One button-style or bold end line; never three competing CTAs |
| **Legal** | Smallest readable; last 1–2s or caption footer |

Rules:
- Prefer **post-composited** type (CapCut/AE) over model-rendered letters  
- Max **7 words** on hook card; **12** on any single caption beat  
- Kerning/logo: brand SVG/PNG only — never AI-redrawn wordmark  

---

## 7) Motion + generation prompts (elite)

Every paste-ready unit prompt must include:

```text
COMMERCIAL — [pattern] — [unit_id]
SHEET LOCK: Image 1=… Image 2=…
CAMERA: [verb + lens feel]
LIGHT: [practicals / key / rim]
MOTION: [what moves; what stays locked]
GRADE: [named grade]
DURATION: Ns
AUDIO PATH: muted+captions | VO in post | native bed (paid-safe)
NEGATIVES: melted type, wrong label, logo redraw, extra fingers, watermark,
  identity drift, plastic skin, default purple glow, illegible text
```

Prefer **I2V from sheet stills** over pure T2V for product/talent. On assembler: keyframe stills that already match grade/palette, then short clip.

---

## 8) Sound design (even when muted-first)

| Track | Spec |
| --- | --- |
| Captions | Carry the story muted |
| VO | One voice; consent/clone rules; not fake personal endorsement |
| Bed | Original / licensed / Suno — **not** uncleared trend audio for paid |
| SFX | 1–3 diegetic hits max (pour, click, notification) |

State loudness intent: dialogue/VO clear over bed; endcard sting optional ≤0.4s.

---

## 9) Endcard craft (last 3–5s)

Build as a **designed plate** (Figma/Canva/CapCut), not a model hallucination:

1. Brand mark (SVG) — correct clear space  
2. One CTA line or button  
3. Optional URL/NAP (user-supplied)  
4. Legal / AI disclosure if required  
5. Hold ≥2.5s; no new product morphs  

Export aspects as **separate** compositions.

---

## 10) Assembler = custom template pipeline

Without Seedance/Higgsfield you still ship elite craft:

1. Lock **Craft system** (palette, type, grade, motion, endcard)  
2. Route video via `alternative-model-routing.md` (Wan → LTX → Grok → …)  
3. Generate **K** keyframes that already look on-brand  
4. Short **C** clips (I2V)  
5. **E** endcard in design tool  
6. CapCut timeline per `production-finish-spec.md`  
7. `render-qa.json` + lint  

The finisher should feel they received a **branded motion template**, not a chat brainstorm.

---

## 11) Strategy spine (before patterns)

Write these in the package (Brief / JTBD area or a short Creative strategy note):

- **Insight** — human truth + tension (one sentence)  
- **Proposition** — ≤12 words, single-minded  
- **Tone** — 3 “is” / 3 “never” words  
- **Brand cue ≤3s** — product color/shape/asset on screen (not a logo sting)

Three hook options as a **stack** each: frame 0 + motion 0–1s + ≤7 words text + first sound. Rank; ship the top one.

## 12) Lint will reject vague craft

`lint-package.mjs` now fails packages that only *have* a Craft system heading:

- <2 HEX colors (unless USER_SUPPLIED brand tokens)  
- Typography = “bold font” / missing type roles  
- Missing Endcard E1 or aspect matrix  
- Adjectives: cinematic, stunning, 8k/4k, sleek, epic, dynamic, vibrant, nice…  
- Compliance leaks in **paid primary** or **captions** (“only when supplied”, “no invented”, ASSUMED, fixture)

## 13) Self-critique craft pass (add to rubric evidence)

Before shipping, answer YES or fix:

- [ ] Could a stranger mute-watch 0–3s and know the situation?  
- [ ] Is product/UI identity locked to sheet refs?  
- [ ] Are type + logo specified for **post**, not hoped from the model?  
- [ ] Is there one clear visual hierarchy per beat (not equal competing elements)?  
- [ ] Does the endcard look designed (margins, logo, one CTA)?  
- [ ] Are tool names real for this session’s access?  
- [ ] Would lint pass craft-hex / craft-vague / copy-leak?
